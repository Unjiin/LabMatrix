# LabMatrix

Лабораторная работа №1 «Матрицы».

Проект содержит:

- статическую библиотеку с шаблонными классами `TMemData` и `TVector`;
- квадратную матрицу `TMatrix`, верхнетреугольную матрицу `TTriangleMatrix` с
  хранением только элементов на диагонали и выше неё;
- консольное приложение «Матричный калькулятор»;
- модульные тесты GoogleTest.

## Сборка

```bash
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

## Калькулятор

Запустите `MatrixApp`. Выберите тип `square` или `triangle`, затем операцию
`add`, `subtract`, `multiply`, `scale`, `trace` или `transpose` (последняя
доступна только для `square`). Укажите размер `n` от 1 до 100 и введите
`n × n` чисел матрицы A по строкам. Для бинарной операции затем введите
матрицу B в том же формате, а для `scale` — множитель. Тип элементов — `double`.
У треугольной матрицы все числа ниже диагонали при вводе должны быть нулями.

Пример ввода для умножения двух квадратных матриц:

```text
square
multiply
2
1 2
3 4
5 6
7 8
```

Результат: строки `[ 19 22 ]` и `[ 43 50 ]`.
